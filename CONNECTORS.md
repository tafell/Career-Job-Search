# Connectors

## How tool references work

Skill files use `~~category` as a placeholder for whatever tool you connect in that category. The skills describe workflows in terms of categories rather than specific products, so they work with whichever tools you use.

## Connectors for this plugin

| Category | Placeholder | Options | Used by |
| --- | --- | --- | --- |
| Email | `~~email` | Gmail, Microsoft Outlook | Reading job alert emails in automated mode |
| File storage | `~~file storage` | Google Drive, OneDrive, Dropbox, a local folder | Reading your base resume, saving tailored documents |
| Application tracker | `~~tracker` | Notion, Google Sheets, Excel, Airtable | Logging applications and run logs |
| Browser | (none) | Claude in Chrome | Reading postings on LinkedIn and employer careers sites |

None are required. Without connectors, paste alerts and postings into chat, attach your resume, and receive documents directly in chat.
