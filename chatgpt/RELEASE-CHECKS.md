# Release Checks

The package passed structural and privacy checks and two isolated instruction trials. Publication is tracked in repository history. These files do not install personal skills or custom assistants.

## Coverage

1. Nine ChatGPT skill files include a standalone public announcement workflow. Four Claude skill files include the matching announcement skill. Two custom assistant configurations provide complete instructions for repeated coaching tasks.
2. Every skill has name and description metadata, a lowercase hyphenated name matching its folder, real trigger phrases, and fewer than three thousand words.
3. Both custom assistant instruction sections are below eight thousand characters. Each includes setup, capabilities, knowledge-file guidance, and conversation starters.
4. Skills include profile lookup, a numbered fallback question, evidence controls, read-only web behavior, and a no-connector fallback. Job evaluations require employer-source verification, expired-posting handling, and verdicts. The announcement skill routes job evaluations separately and does not screen compensation.

Replace it with your own minimum base salary. --> with an adjacent comment. Missing pay, unknown currency, and values of 0 or 1 cannot establish compensation compatibility.
6. The shared profile remains unchanged. The existing Claude skills were updated before publication to align evidence, verdict, compensation, and web rules. The package does not contain filled-in profiles, resume files, private tracker records, or source conversation exports.

## Privacy and editorial review

1. Searched package files for the source user's name, location, employer and contact names, email addresses, private workspace links, file and database identifiers, local paths, currency figures, unexpected large numbers, and em dashes. No prohibited matches remained.
2. Reviewed remaining numbers and links by context. Public documentation article numbers and the release date are not compensation or private identifiers.
3. Personal compensation, candidate history, titles, achievements, contacts, locations, subscription senders, file destinations, and writing preferences were replaced with profile references or omitted.
4. Checked numbered lists, instruction lengths, matching skill names, and the required portable metadata. The package uses requested technical filenames and product names where necessary; prose spells out general terminology.
5. Resolved conflicting wording that initially implied job-fit verdict labels should apply to all coaching feedback. Opportunity and career-lane evaluations use the four verdicts; interview-answer coaching uses readiness feedback.
6. Documented the shared template's missing-compensation conflict instead of modifying it. Documented current custom assistant availability instead of assuming everyone can create one.

## Limitations

1. These were two isolated instruction trials, not a comparative performance study or proof of behavior in every model.
2. Live email access, tracker writes, scheduled execution, document rendering, and custom assistant installation were not tested. No candidate email or application records were changed.
3. Original custom assistant instructions and a complete saved-prompt collection were unavailable. The configurations are new adaptations, not recovered exports.
4. Outreach is newly composed guidance. Cover letter and tracking methods draw on the existing Claude references. Interview and career-direction workflows draw on visible process history and the supplied evidence standards.
5. Source-site mechanics vary. The workflows use supported read-only access and pasted-text fallbacks rather than hard-coded page selectors or assumptions about login access.
6. Additional profile settings and differences from the Claude versions are listed in README.md. None were silently added to the shared template.
